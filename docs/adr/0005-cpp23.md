# ADR 0005 — C++23 en lugar de C++20

- Estado: aceptado (aprobado por el autor el 2026-10-18)
- Fecha: 2026-10-18

## Contexto

Las convenciones piden manejar errores con `std::expected` y el stack inicial fijaba C++20.
`std::expected` es de C++23: con `/std:c++20`, la STL de MSVC 19.44 lo desactiva
(warning STL4038) y el código no compila.

## Opciones

1. Subir a C++23.
2. Mantener C++20 y escribir un `core::Result<T>` propio.

## Decisión

C++23 (`CMAKE_CXX_STANDARD 23`). MSVC 17.14 y clang-cl compilan el proyecto sin warnings en
ese modo. Usar el tipo estándar evita mantener código propio y la sintaxis coincide con la
documentación que el autor encontrará en internet.

## Consecuencias

- Hace falta MSVC ≥ 17.10 o clang ≥ 17 (ya es el caso en local y en la CI).
- Quedan disponibles `std::print`, `std::ranges::to` y *deducing this*; se usarán solo
  cuando aporten claridad.
